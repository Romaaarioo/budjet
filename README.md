# 💰 Мои Финансы

Простое веб-приложение для учёта личных финансов: доходов, расходов и инвестиций.

## Возможности

- 📊 **Обзор** — общий баланс, доходы и расходы за текущий месяц, диаграмма расходов по категориям
- 📝 **История** — все операции, сгруппированные по дням, с возможностью удаления
- 📈 **Инвестиции** — вложенные суммы, текущая стоимость, прибыль/убыток в рублях и процентах
- 📱 Адаптивный дизайн под мобильный телефон
- 🔒 Все данные хранятся только в вашем браузере (localStorage) — ничего не отправляется в интернет

## Как пользоваться

1. Откройте приложение по ссылке GitHub Pages
2. Нажмите **«+»**, чтобы добавить доход или расход
3. На вкладке «Инвестиции» кнопка **«+»** добавляет инвестицию
4. Совет: добавьте страницу на главный экран телефона («Добавить на главный экран» в меню браузера) — приложение будет открываться как обычное

## Технологии

Чистый HTML + CSS + JavaScript, без фреймворков и сборки.

## Запуск локально

```bash
python -m http.server 8000
```

затем откройте http://localhost:8000
